# Contributing

One entry per pull request.

- **Format:** `- [Name](URL) — One-line description. *License or free note.*`
- **Bar for entry:** open-source software, open-licensed resources, or genuinely useful free/free-tier AI tools. No affiliate links, no paywalled tools presented as free.
- **Verify the link** resolves before submitting.
- **Say the license** if you know it (MIT, Apache-2.0, GPL, CC0…). 
- Put the entry in the right section, roughly alphabetical within it.
- The "Starred by d123d" section is generated from the GitHub API (`build_list.py` + `data/starred.json`) — don't hand-edit it; star the repo and it lands on the next refresh.
